⚡

电荷与电流

电的本质是电荷的定向移动

自然界只有两种电荷：正电荷和负电荷。同种电荷相互排斥，异种电荷相互吸引。

电流：电荷的定向移动形成电流。规定正电荷移动方向为电流方向（实际金属导体中是自由电子反向移动）。

电流强度：I = Q / t（单位时间通过导体横截面的电荷量），单位：安培(A)。

🔌

串联电路与并联电路 —— 完整对比

初中物理最常考的知识点，没有之一！

对比项串联电路并联电路
连接方式首尾顺次相连（一条路）首首相连、尾尾相连（多条路）
电流特点I = I₁ = I₂（处处相等）I = I₁ + I₂（干路 = 各支路和）
电压特点U = U₁ + U₂（总电压 = 各分压和）U = U₁ = U₂（各支路电压相等）
电阻特点R = R₁ + R₂（总电阻 > 任一分电阻）1/R = 1/R₁ + 1/R₂（总电阻 < 任一分电阻）
用电器关系相互影响（一个断开，全部不工作）互不影响（各自独立工作）
开关控制一只开关控制所有用电器干路开关控制所有，支路开关只控该支路
生活应用节日装饰彩灯（老式）、手电筒家庭电路、路灯、教室灯具
记忆口诀"串流等、压分、阻加大""并压等、流分、阻减小"
🏠为什么家里所有电器都是并联的？因为并联互不影响——关掉电视不影响冰箱工作，且所有电器都获得相同的 220V 电压。如果是串联，关掉电视全家断电！
💡为什么并联电路总电阻反而变小？多一条路就是多一个"通道"，相当于导体的横截面积变大——电阻自然变小。
🌘

电阻与变阻器

阻碍电流的"路障"

电阻 R表示导体对电流的阻碍作用。单位：欧姆(Ω)。

影响电阻的因素：材料、长度（越长电阻越大）、横截面积（越细电阻越大）、温度（一般温度越高电阻越大）。

滑动变阻器：通过改变接入电路的电阻丝长度来改变电阻。接线原则："一上一下"——一个接上接线柱、一个接下接线柱。

🔈音量旋钮就是变阻器——旋转改变电阻 → 改变电路中的电流 → 改变喇叭音量大小。
📺台灯调光——也是变阻器原理。不过现代 LED 台灯多用电脉冲调光（更省电），原理不同。
🌇光敏电阻——光照越强电阻越小。路灯自动开关就用它：天黑时电阻增大，触发电路开灯。
⚡

欧姆定律

I = U / R —— 电学的"牛顿定律"

I = U / R
I 电流 (A) U 电压 (V) R 电阻 (Ω)

变形：U = IR，R = U / I。注意：R = U/I 不是定义式——只能说电阻等于电压与电流的比值，不能说"电阻与电压成正比"（电阻是导体本身的属性！）。

伏安法：R =  U / I
🔬 Tips 图示

伏安法测电阻

电流表（A）串联在被测电路中测电流 I；电压表（V）并联在 Rx 两端测电压 U。根据 R = U/I 算出电阻。改变滑动变阻器取多组数据求平均值减小误差。

💡

电功与电功率 —— 额定 vs 实际

灯泡上标的"220V 40W"是什么意思？

电功：W = UIt（电流做功 = 电压 × 电流 × 时间），单位：焦耳(J)。生活中常用：千瓦时(kWh)——"度"。1 度 = 1 kWh = 3.6 × 10⁶ J。

电功率：P = UI（单位时间电流做的功），单位：瓦特(W)。

P = UI = I²R = U²/R
P 电功率 (W) U 电压 (V) I 电流 (A)

额定功率 vs 实际功率：灯泡上写的"220V 40W"——220V 是额定电压，40W 是额定功率。如果实际电压低于 220V，实际功率就低于 40W，灯泡变暗。

💡同样 220V 电压下，100W 灯泡比 40W 灯泡亮——因为 P 更大，单位时间电流做功更多。计算公式：P实/P额 = (U实²/R) / (U额²/R) = U实²/U额²。如果电压降到 110V，功率只有额定的 1/4！

🔥

焦耳定律 —— 「电流生热的数学」

电流通过导体时为什么发热？发了多少热？

Q = I² R t
Q 热量 (J) I 电流 (A) R 电阻 (Ω) t 时间 (s)

电流通过导体产生的热量与电流的平方成正比，与电阻成正比，与通电时间成正比。这就是为什么电流翻倍时发热量翻 4 倍！

电热器原理：利用电流的热效应——电饭煲、电热水壶、电暖器、电烙铁。电热器的核心是电阻丝（电阻大、熔点高）。

🍳电饭煲——电流通过电阻丝发热，把饭煮熟。如果焦耳定律中的 I 变为两倍，Q 变为 4 倍——所以短路时电流激增，导线瞬间烧毁！
💡白炽灯靠电流通过钨丝发热到白炽状态发光——95% 的电能变成热能，只有 5% 变成光，效率极低。LED 灯不靠发热发光，效率高得多。
🏠

家庭电路 —— 「三根线守护全家安全」

你家墙壁里的电线是怎么接的？

家庭电路电压：220V 交流电。三根线：

· 火线（L）：红色/棕色，对地电压 220V，是"来电"的线。

· 零线（N）：蓝色，与火线构成回路，正常情况下对地电压为 0。

· 地线（E）：黄绿双色，与大地相连，电器外壳漏电时把电流导入大地——保护人的生命线！

漏电保护器：检测火线和零线的电流差。正常时 I火 = I零（差值为 0）。有人触电时电流通过人体流入大地，I火 > I零——漏电保护器立即跳闸断电（0.1 秒内）。

⚠为什么不能用湿手摸开关？水是导体——湿手摸开关时，电流可能通过水+人体流入大地，形成触电回路！

火线（红）提供 220V 电压，零线（蓝）构成回路，地线（黄绿）保护安全。漏电保护器监测火线零线电流差。所有用电器并联接入。

⚠

安全用电要点

电是好朋友，但发脾气时要命！

安全电压：不高于 36V。人体安全电流：不超过 10mA（交流）。

触电原因：人体直接或间接接触火线，电流经人体流入大地。

安全用电原则：①不接触低压带电体（火线）；②不靠近高压带电体；③不用湿手摸电器；④不损坏绝缘层；⑤金属外壳用电器必须接地。

🌉雷雨天不要在树下躲雨——雷电（高压放电）会击中高处物体，电流沿树干到地面形成跨步电压，造成触电。
✨ 趣味冷知识
小鸟站在高压线上为什么没事？
小鸟两脚站在同一根高压线上，两脚间距极小，两脚间的电压差几乎为零——没有电压差就没有电流通过身体。如果小鸟一脚踩火线一脚踩零线……那一刻它就变成了一只"电烤小鸟"。所以不是小鸟不怕电，是它聪明地站对了地方！
✨ 趣味冷知识
爱迪生和特斯拉的"电流大战"
19 世纪末，爱迪生推广直流电，特斯拉推广交流电。爱迪生甚至用电死大象来证明交流电"危险"——但最终交流电赢了，因为交流电能通过变压器升压远距离传输，损耗极小。今天你家用的就是交流电，但手机充电器把交流转为直流——两人都赢了。
✨ 趣味冷知识
人体电阻有多大？
干燥皮肤电阻约为 10000~100000 Ω，但皮肤潮湿时电阻骤降至 1000 Ω 以下！这就是为什么游泳后摸电器特别危险——皮肤湿润时 36V 就可能致命。

⚠ 常见误区提醒

  • ❌ "串联电路中电流处处相等，所以各用电器亮度相同" → ✅ 串联电流相等，但用电器电阻不同 → 电压分配不同（U=IR）→ 实际功率不同（P=UI）→ 亮度不同！
  • ❌ "零线没有电，摸着没事" → ✅ 零线在正常工作时对地电压为 0，但电路断开时零线可能带电！维修必须切断总闸。
  • ❌ "额定功率大的灯泡一定更费电" → ✅ 不一定！A 用 100W 开 10 分钟（0.017 度）vs B 用 20W 开 2 小时（0.04 度）——B 反而更费电。
  • ❌ "焦耳定律 I²R 中电流平方意味着任何时候 I 影响最大" → ✅ 正确——这就是为什么电线发热的罪魁祸首是过载（电流过大），不是电压过高。
  • ❌ "测电阻时电压表串联、电流表并联" → ✅ 反了！电压表并联（测两端电压），电流表串联（让电流通过）。

🧪 家庭小实验：水果电池

  1. 准备：一个柠檬（或土豆）、一片铜片（硬币也行）、一片锌片（镀锌钉）。
  2. 把铜片和锌片插入柠檬（不要相碰），用导线连接 LED 小灯泡或电子表。
  3. 观察——LED 亮了！水果里的酸性汁液充当了电解质。
  4. 多串几个水果电压更高，试试能点亮几个 LED！

🧪 家庭小实验：识别导体和绝缘体

  1. 准备：一节电池、一个小灯泡、三根导线。连接成简单电路。
  2. 电路留一个"缺口"，往缺口里"塞"不同物品：铅笔芯、橡皮、硬币、塑料尺子、钥匙……
  3. 灯泡亮→导体，不亮→绝缘体。
  4. 惊喜：铅笔芯（石墨）是导体！纯水几乎不导电，但盐水导电性很好。

🧪 家庭小实验：感受焦耳定律

  1. 准备：一节 1.5V 电池、一段细铁丝（或铅笔芯粉末）。
  2. 用导线连接电池和细铁丝——几秒后铁丝变热！
  3. 这就是焦耳定律 Q = I²Rt 的直观体验——电流通过电阻产生了热量。
  4. 注意：不要短路太长时间，以免烫伤或损坏电池。
