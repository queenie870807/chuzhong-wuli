⚡

电荷与电流

电的本质是电荷的定向移动

自然界只有两种电荷：正电荷和负电荷。同种电荷相互排斥，异种电荷相互吸引。

电流：电荷的定向移动形成电流。规定正电荷移动方向为电流方向（实际金属导体中是自由电子反向移动）。

电流强度：I = Q / t（单位时间通过导体横截面的电荷量），单位：安培(A)。

🔌

串联电路与并联电路 —— 完整对比

初中物理最常考的知识点，没有之一！

对比项串联电路并联电路
连接方式首尾顺次相连（一条路）首首相连、尾尾相连（多条路）
电流特点I = I₁ = I₂（处处相等）I = I₁ + I₂（干路 = 各支路和）
电压特点U = U₁ + U₂（总电压 = 各分压和）U = U₁ = U₂（各支路电压相等）
电阻特点R = R₁ + R₂（总电阻 > 任一分电阻）1/R = 1/R₁ + 1/R₂（总电阻 < 任一分电阻）
用电器关系相互影响（一个断开，全部不工作）互不影响（各自独立工作）
开关控制一只开关控制所有用电器干路开关控制所有，支路开关只控该支路
生活应用节日装饰彩灯（老式）、手电筒家庭电路、路灯、教室灯具
记忆口诀"串流等、压分、阻加大""并压等、流分、阻减小"
🏠为什么家里所有电器都是并联的？因为并联互不影响——关掉电视不影响冰箱工作，且所有电器都获得相同的 220V 电压。如果是串联，关掉电视全家断电！
💡为什么并联电路总电阻反而变小？多一条路就是多一个"通道"，相当于导体的横截面积变大——电阻自然变小。
🌘

电阻与变阻器

阻碍电流的"路障"

电阻 R表示导体对电流的阻碍作用。单位：欧姆(Ω)。

影响电阻的因素：材料、长度（越长电阻越大）、横截面积（越细电阻越大）、温度（一般温度越高电阻越大）。

滑动变阻器：通过改变接入电路的电阻丝长度来改变电阻。接线原则："一上一下"——一个接上接线柱、一个接下接线柱。

🔈音量旋钮就是变阻器——旋转改变电阻 → 改变电路中的电流 → 改变喇叭音量大小。
📺台灯调光——也是变阻器原理。不过现代 LED 台灯多用电脉冲调光（更省电），原理不同。
🌇光敏电阻——光照越强电阻越小。路灯自动开关就用它：天黑时电阻增大，触发电路开灯。
⚡

欧姆定律

I = U / R —— 电学的"牛顿定律"

I = U / R
I 电流 (A) U 电压 (V) R 电阻 (Ω)

变形：U = IR，R = U / I。注意：R = U/I 不是定义式——只能说电阻等于电压与电流的比值，不能说"电阻与电压成正比"（电阻是导体本身的属性！）。

伏安法：R =  U / I
🔬 Tips 图示

伏安法测电阻

电流表（A）串联在被测电路中测电流 I；电压表（V）并联在 Rx 两端测电压 U。根据 R = U/I 算出电阻。改变滑动变阻器取多组数据求平均值减小误差。

💡

电功与电功率 —— 额定 vs 实际

灯泡上标的"220V 40W"是什么意思？

电功：W = UIt（电流做功 = 电压 × 电流 × 时间），单位：焦耳(J)。生活中常用：千瓦时(kWh)——"度"。1 度 = 1 kWh = 3.6 × 10⁶ J。

电功率：P = UI（单位时间电流做的功），单位：瓦特(W)。

P = UI = I²R = U²/R
P 电功率 (W) U 电压 (V) I 电流 (A)

额定功率 vs 实际功率：灯泡上写的"220V 40W"——220V 是额定电压，40W 是额定功率。如果实际电压低于 220V，实际功率就低于 40W，灯泡变暗。

💡同样 220V 电压下，100W 灯泡比 40W 灯泡亮——因为 P 更大，单位时间电流做功更多。计算公式：P实/P额 = (U实²/R) / (U额²/R) = U实²/U额²。如果电压降到 110V，功率只有额定的 1/4！

🔥

焦耳定律 —— 「电流生热的数学」

电流通过导体时为什么发热？发了多少热？

Q = I² R t
Q 热量 (J) I 电流 (A) R 电阻 (Ω) t 时间 (s)

电流通过导体产生的热量与电流的平方成正比，与电阻成正比，与通电时间成正比。这就是为什么电流翻倍时发热量翻 4 倍！

电热器原理：利用电流的热效应——电饭煲、电热水壶、电暖器、电烙铁。电热器的核心是电阻丝（电阻大、熔点高）。

🍳电饭煲——电流通过电阻丝发热，把饭煮熟。如果焦耳定律中的 I 变为两倍，Q 变为 4 倍——所以短路时电流激增，导线瞬间烧毁！
💡白炽灯靠电流通过钨丝发热到白炽状态发光——95% 的电能变成热能，只有 5% 变成光，效率极低。LED 灯不靠发热发光，效率高得多。
🏠

家庭电路 —— 「三根线守护全家安全」

你家墙壁里的电线是怎么接的？

家庭电路电压：220V 交流电。三根线：

· 火线（L）：红色/棕色，对地电压 220V，是"来电"的线。

· 零线（N）：蓝色，与火线构成回路，正常情况下对地电压为 0。

· 地线（E）：黄绿双色，与大地相连，电器外壳漏电时把电流导入大地——保护人的生命线！

漏电保护器：检测火线和零线的电流差。正常时 I火 = I零（差值为 0）。有人触电时电流通过人体流入大地，I火 > I零——漏电保护器立即跳闸断电（0.1 秒内）。

⚠为什么不能用湿手摸开关？水是导体——湿手摸开关时，电流可能通过水+人体流入大地，形成触电回路！

家庭电路：火线(L) + 零线(N) + 地线(E)

火线（红）提供 220V 电压，零线（蓝）构成回路，地线（黄绿）保护安全。漏电保护器监测火线零线电流差。所有用电器并联接入。

⚠

安全用电要点

电是好朋友，但发脾气时要命！

安全电压：不高于 36V。人体安全电流：不超过 10mA（交流）。

触电原因：人体直接或间接接触火线，电流经人体流入大地。

安全用电原则：①不接触低压带电体（火线）；②不靠近高压带电体；③不用湿手摸电器；④不损坏绝缘层；⑤金属外壳用电器必须接地。

🌉雷雨天不要在树下躲雨——雷电（高压放电）会击中高处物体，电流沿树干到地面形成跨步电压，造成触电。
✨ 趣味冷知识
小鸟站在高压线上为什么没事？
小鸟两脚站在同一根高压线上，两脚间距极小，两脚间的电压差几乎为零——没有电压差就没有电流通过身体。如果小鸟一脚踩火线一脚踩零线……那一刻它就变成了一只"电烤小鸟"。所以不是小鸟不怕电，是它聪明地站对了地方！
✨ 趣味冷知识
爱迪生和特斯拉的"电流大战"
19 世纪末，爱迪生推广直流电，特斯拉推广交流电。爱迪生甚至用电死大象来证明交流电"危险"——但最终交流电赢了，因为交流电能通过变压器升压远距离传输，损耗极小。今天你家用的就是交流电，但手机充电器把交流转为直流——两人都赢了。
✨ 趣味冷知识
人体电阻有多大？
干燥皮肤电阻约为 10000~100000 Ω，但皮肤潮湿时电阻骤降至 1000 Ω 以下！这就是为什么游泳后摸电器特别危险——皮肤湿润时 36V 就可能致命。

⚠ 常见误区提醒

  • ❌ "串联电路中电流处处相等，所以各用电器亮度相同" → ✅ 串联电流相等，但用电器电阻不同 → 电压分配不同（U=IR）→ 实际功率不同（P=UI）→ 亮度不同！
  • ❌ "零线没有电，摸着没事" → ✅ 零线在正常工作时对地电压为 0，但电路断开时零线可能带电！维修必须切断总闸。
  • ❌ "额定功率大的灯泡一定更费电" → ✅ 不一定！A 用 100W 开 10 分钟（0.017 度）vs B 用 20W 开 2 小时（0.04 度）——B 反而更费电。
  • ❌ "焦耳定律 I²R 中电流平方意味着任何时候 I 影响最大" → ✅ 正确——这就是为什么电线发热的罪魁祸首是过载（电流过大），不是电压过高。
  • ❌ "测电阻时电压表串联、电流表并联" → ✅ 反了！电压表并联（测两端电压），电流表串联（让电流通过）。

🧪 家庭小实验：水果电池

  1. 准备：一个柠檬（或土豆）、一片铜片（硬币也行）、一片锌片（镀锌钉）。
  2. 把铜片和锌片插入柠檬（不要相碰），用导线连接 LED 小灯泡或电子表。
  3. 观察——LED 亮了！水果里的酸性汁液充当了电解质。
  4. 多串几个水果电压更高，试试能点亮几个 LED！

🧪 家庭小实验：识别导体和绝缘体

  1. 准备：一节电池、一个小灯泡、三根导线。连接成简单电路。
  2. 电路留一个"缺口"，往缺口里"塞"不同物品：铅笔芯、橡皮、硬币、塑料尺子、钥匙……
  3. 灯泡亮→导体，不亮→绝缘体。
  4. 惊喜：铅笔芯（石墨）是导体！纯水几乎不导电，但盐水导电性很好。

🧪 家庭小实验：感受焦耳定律

  1. 准备：一节 1.5V 电池、一段细铁丝（或铅笔芯粉末）。
  2. 用导线连接电池和细铁丝——几秒后铁丝变热！
  3. 这就是焦耳定律 Q = I²Rt 的直观体验——电流通过电阻产生了热量。
  4. 注意：不要短路太长时间，以免烫伤或损坏电池。

1
2024年上海中考 · 计算题 · 4分 — 欧姆定律
如图所示的电路中，电源电压U=6V保持不变，定值电阻R₁=10Ω，滑动变阻器R₂的最大阻值为20Ω。求：（1）当滑片P在R₂中点时，电路中的电流I；（2）此时R₁两端的电压U₁和R₂两端的电压U₂。
🔎 解题思路
  1. 分析电路：R₁和R₂串联。R₂在中点时，R₂=10Ω。总电阻 R总 = R₁+R₂ = 10+10 = 20Ω。
  2. 求电流：I = U/R总 = 6/20 = 0.3A。
  3. 求各电压：U₁ = IR₁ = 0.3×10 = 3V；U₂ = IR₂ = 0.3×10 = 3V。（串联分压，电阻相等则电压相等。）
  4. 验证：U₁+U₂ = 3+3 = 6V = U ✓
✅ 答案：（1）I = 0.3A；（2）U₁ = 3V，U₂ = 3V
⚠ 易错陷阱："滑片在R₂中点"意味着R₂接入电路的阻值为最大值的一半（10Ω），不是R₂总阻值20Ω。串联电路中I处处相等，不要错误地认为R₁和R₂的电流不同。串联分压公式 U₁:U₂=R₁:R₂ 可以快速验证。
2
2023年上海中考 · 计算题 · 5分 — 欧姆定律+串并联综合
如图，电源电压U=12V。开关S闭合时，R₁=6Ω与R₂=12Ω并联。求：（1）通过R₁的电流I₁；（2）通过R₂的电流I₂；（3）干路总电流I；（4）电路的总电阻R。
🔎 解题思路
  1. 并联电压特点：并联支路两端电压相等，都等于电源电压 U=12V。
  2. I₁ = U/R₁ = 12/6 = 2A。
  3. I₂ = U/R₂ = 12/12 = 1A。
  4. 干路电流：I = I₁+I₂ = 2+1 = 3A。
  5. 总电阻：R = U/I = 12/3 = 4Ω。或者用并联公式 1/R = 1/6+1/12 = 3/12 → R=4Ω。
✅ 答案：（1）I₁=2A；（2）I₂=1A；（3）I=3A；（4）R=4Ω
⚠ 易错陷阱：并联电路中各支路电压相等但不等于各支路电流相等。总电阻小于任意一个支路电阻（4Ω < 6Ω），因为并联相当于增加了导体的横截面积。很多同学错误地认为并联总电阻在两者之间——实际上并联总电阻一定小于最小支路电阻。
3
2024年上海中考 · 计算题 · 5分 — 电功率
某电热水壶铭牌上标有"220V 1100W"。求：（1）正常工作时的电流；（2）正常工作时的电阻；（3）若实际电压为200V，此时的实际功率是多少？（假设电阻不变）
🔎 解题思路
  1. 正常工作电流：P=UI → I=P/U=1100/220=5A。
  2. 电阻：R=U²/P=220²/1100=48400/1100=44Ω（或用R=U/I=220/5=44Ω）。
  3. 实际功率：U实=200V，R不变=44Ω。P实=U实²/R=200²/44=40000/44≈909W。
  4. 规律：电压下降，功率下降（电压降为原来的200/220≈0.91，功率降为原来的≈0.83，因为P∝U²）。
✅ 答案：（1）5A；（2）44Ω；（3）约909W
⚠ 易错陷阱：实际功率不能用P=UI直接算（因为U变了I也会变）。正确做法是先算电阻R（不变的量），再用P=U²/R算实际功率。绝对不能直接用 I=P额/U额 算出来的电流去乘实际电压——电流已经变了！

2022年上海中考 · 计算题 · 3分 — 焦耳定律
一根电热丝的电阻为50Ω，通过它的电流为2A。求：（1）通电1分钟产生的热量；（2）如果电流增大到4A，同样通电1分钟，产生的热量是原来的几倍？
🔎 解题思路
  1. 第一问：Q = I²Rt。t=1min=60s。Q = 2² × 50 × 60 = 4 × 50 × 60 = 12000J。
  2. 第二问：电流从2A变为4A（变为2倍）。Q ∝ I²，热量变为原来的 2²=4 倍。不需要重新计算完整过程：Q新/Q原 = (4/2)² = 4倍。
  3. 关键结论：焦耳定律中热量与电流的平方成正比——电流翻倍，热量翻四倍！
✅ 答案：（1）12000J；（2）4倍
⚠ 易错陷阱：Q∝I²不是Q∝I！很多同学以为电流翻倍热量只翻倍——不对，是翻四倍！这是焦耳定律最重要的非线性关系。另外注意时间单位必须换算成秒（1min=60s），如果直接用"1分钟"算，结果是错的。

2023年上海中考 · 选择题 · 2分 — 家庭电路
关于家庭电路与安全用电，下列说法正确的是（ ）
🔎 解题思路
  1. 逐个判断选项：A."保险丝用铜丝代替更安全"——错误，铜丝熔点高，电流过大时不会熔断，失去保护作用。B."开关应接在零线上"——错误，开关应接在火线上，断开时才能确保用电器不带电。C."使用三孔插座时，地线可以悬空不接"——错误，地线是防触电保护的关键。D."测电笔氖管发光说明接触的是火线"——正确。
  2. 安全用电核心原则：火线进开关，零线进灯头；金属外壳必须接地；保险丝不可用铜丝/铁丝替代。
✅ 答案：D（测电笔氖管发光说明接触的是火线）
⚠ 易错陷阱：开关接火线是安全用电最基本的原则——因为断开开关后要确保用电器不带电。如果开关接在零线上，即使断开，用电器仍与火线相连，人触碰可能触电。保险丝不能用铜丝代替，原因是铜丝熔点太高（约1083°C），电流过大时不会及时熔断。

易错题 1 — 串联分压
两个电阻R₁=3Ω、R₂=6Ω串联接在9V电源上，R₁两端的电压为（ ）
A. 3V B. 6V C. 4.5V D. 9V
✅ 正确答案：A
错误选项分析：串联分压：U₁:U₂=R₁:R₂=3:6=1:2。U₁=9×(1/3)=3V。选B的同学可能搞反了比例——电阻大的分压多。口诀："串联分压，大电阻大电压"；分压公式 U₁=U×R₁/(R₁+R₂)。
易错题 2 — 并联分流
R₁=4Ω和R₂=12Ω并联接在电源上，通过R₁的电流为3A，则通过R₂的电流为（ ）
A. 3A B. 1A C. 9A D. 0.5A
✅ 正确答案：B
错误选项分析：并联分流：I₁:I₂=R₂:R₁=12:4=3:1。I₂=I₁/3=3/3=1A。口诀："并联分流，小电阻大电流"。注意并联分流公式中电阻比是反比——I₁/I₂=R₂/R₁。
易错题 3 — 额定功率vs实际功率
灯泡标有"220V 100W"，接在110V电源上（假设灯丝电阻不变），实际功率为（ ）
A. 100W B. 50W C. 25W D. 200W
✅ 正确答案：C
错误选项分析：R=U额²/P额=220²/100=484Ω。P实=U实²/R=110²/484=12100/484=25W。电压减半→功率变为原来的1/4（因为P∝U²）。选B（50W）的同学误以为P∝U——错了！功率与电压的平方成正比。
易错题 4 — 电能单位换算
一个100W的灯泡正常工作5小时，消耗的电能是多少千瓦时（度）？（ ）
A. 500度 B. 0.5度 C. 5度 D. 50度
✅ 正确答案：B
错误选项分析：W=Pt=0.1kW×5h=0.5kW·h=0.5度。注意：100W=0.1kW，不是100kW！单位必须统一。1度=1kW·h。如果用国际单位：W=100×5×3600=1800000J=1.8×10⁶J。
易错题 5 — 短路判断
如图，当开关S闭合后，灯泡L₁亮、L₂不亮，可能的原因是（ ）
A. L₂的灯丝断了 B. L₂被短路（导线两端直接相连） C. 电源电压太小 D. L₂的功率太小
✅ 正确答案：B
错误选项分析：串联电路中一个亮一个不亮→不亮的灯泡被短路（电流绕过了它）。如果灯丝断了（A），串联电路断路，两个都不亮。短路与断路的区别：短路=有电流但不经过该灯泡（灯泡不亮但其他可能亮）；断路=无电流（全部不亮）。

🧪 实验探究 中考必考实验

🧪 伏安法测电阻

上海中考最高频电学实验——近3年出现3次，分值4~5分

🛠 实验器材
  • 电源（电池组或学生电源）
  • 待测电阻 R（未知阻值）
  • 电流表（0~0.6A / 0~3A）
  • 电压表（0~3V / 0~15V）
  • 滑动变阻器（保护电路+多次测量）
  • 开关、导线若干
📝 实验步骤
  • 步骤1：按电路图连接实物：电流表串联在电路中（正进负出），电压表并联在待测电阻两端（正进负出），滑动变阻器"一上一下"接法，开关断开。
  • 步骤2：闭合开关前，将滑动变阻器滑片移到阻值最大处（保护电路）。
  • 步骤3：闭合开关，调节滑动变阻器，记录一组电压U和电流I的数值。重复3次，记录3组不同的U、I值。
  • 步骤4：用 R=U/I 计算每次的电阻值，取平均值作为最终结果 R=(R₁+R₂+R₃)/3。
🔬 实验原理与结论
  • 原理：R = U / I（欧姆定律的变形）。通过测量电阻两端的电压和通过电阻的电流，计算电阻值。
  • 多次测量的目的：求平均值减小实验误差（注意：不是"寻找普遍规律"！测电阻实验的多次测量是为了减小误差，探究性实验的多次测量才是为了找规律）。
  • 滑动变阻器的作用：①保护电路（闭合开关前调至最大）；②改变待测电阻两端的电压和电流，实现多次测量。
🔎 考试常见设问
  1. "为什么闭合开关前要把变阻器调到最大阻值？"——保护电路，防止电流过大烧坏电流表或电源。
  2. "本实验多次测量的目的是什么？"——求平均值，减小实验误差（注意：和探究欧姆定律实验的目的不同，后者是为了找普遍规律）。
  3. "如果电流表和电压表的位置接反了会怎样？"——电流表内阻很小，如果并联在电阻两端会造成短路，烧坏电流表！电压表内阻很大，串联在电路中会使电路几乎断路。
  4. "为什么不用小灯泡代替定值电阻？"——小灯泡的电阻随温度升高而增大（灯丝电阻受温度影响），不能求平均值，只能用定值电阻。
  5. "如果只有一组数据，能否得出准确结果？"——可以算出电阻值，但误差较大。多次测量取平均值可以提高精确度。
