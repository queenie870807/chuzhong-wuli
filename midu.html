📚 核心概念
⚖

质量 —— 「换个地方还是我」

物体所含物质的多少——走到宇宙尽头都不变

质量 m是物体的一种属性——不随物体的形状、状态、位置、温度的改变而改变。

单位：千克(kg)、克(g)、毫克(mg)、吨(t)。1 t = 1000 kg，1 kg = 1000 g，1 g = 1000 mg。

👶一个学生的质量约 50 kg。到月球上质量还是 50 kg——重力变了，但质量不变！
🎂一块蛋糕被切开，每块的质量变了（形状变了），但各块质量之和 = 原来质量——这是质量守恒。
🏂一块冰融化成水——形状和状态都变了，但质量不变。物理变化不改变质量。

密度 —— 「同样大小，谁更沉」

某种物质单位体积的质量叫做这种物质的密度。密度是物质的一种特性——每种物质有固定的密度（常温常压下）。

ρ = m / V
ρ = 密度 (kg/m³ 或 g/cm³) m = 质量 (kg 或 g) V = 体积 (m³ 或 cm³)

换算：1 g/cm³ = 1000 kg/m³。水的密度：1.0×10³ kg/m³ = 1 g/cm³——这是初中物理最重要的「基准密度」。

💡

理解密度 —— 「铁比棉花重」对不对？

严格说不对——要看体积！

「铁比棉花重」在日常语言中没问题，但物理学上不严谨：应该是相同体积的铁比棉花质量大，即铁的密度比棉花大。

密度是物质的特性：同种物质密度相同（理想情况下），与质量和体积无关。一杯水和一桶水密度一样。

区分密度和比重：密度 = m/V（有单位），比重 = ρ物 / ρ水（无单位的比值）。

💰1 kg 棉花和 1 kg 铁——质量相同，但棉花体积巨大。因为密度不同：ρ铁 ≈ 7.9 g/cm³，ρ棉花 ≈ 0.01 g/cm³。

测固体密度 —— 排水法

步骤：① 用天平称固体质量 m；② 量筒倒入适量水，记录 V₁；③ 将固体完全浸没水中，记录 V₂；④ 体积 V = V₂ - V₁；⑤ ρ = m / (V₂ - V₁)。

图中石头浸入量筒后水面上升，上升的体积就是石头的体积。联合天平称出的质量，密度就求出来了。

🍹

测液体密度 —— 「两步称重法」

比测固体多一步，但不难

步骤：① 用天平称空烧杯质量 m₁；② 倒入液体，称烧杯+液体总质量 m₂ → 液体质量 m = m₂ - m₁；③ 将液体倒入量筒，读出体积 V；④ ρ = (m₂ - m₁) / V。

更精确的方法：先称烧杯+液体总质量 m₁，倒入量筒后称剩余烧杯+液体质量 m₂ → 量筒里的液体质量 = m₁ - m₂。这样避免了液体倒不干净带来的误差。

🍹测牛奶密度：ρ牛奶 大约 1.03 g/cm³——比水稍大。如果测出来是 1.0 左右，怀疑是掺水了。
🌕

特殊测量方法 —— 「不能沉底怎么办？」

漂浮物体和超大物体的测量技巧

漂浮物（ρ物 < ρ水）：细针压入法——用细针把漂浮物完全压入水中，读 V₂。或悬垂法——用重物把漂浮物拉下水。

溶于水的固体：用不溶的液体（如油）代替水，或用「埋沙法」——用细沙填平测量。

粉末状固体：直接倒入量筒压实测量，注意避气泡。

🍒一块木块漂浮——先用天平称质量 12 g，用针压入水中后体积 V₂ - V₁ = 20 cm³ → ρ = 0.6 g/cm³。

密度与温度 —— 「热胀冷缩让我变轻」

一般物体热胀冷缩：温度升高 → 体积变大 → 但质量不变 → 密度变小。

图中左边热气体分子间距大（体积大），右边冷气体分子间距小（体积小）。同质量气体，热的气体密度更小。

水的反常：水在 4°C 时密度最大（1.000 g/cm³）。0°C 的冰密度约 0.9 g/cm³——冰浮在水面上，保护了水下生物。

✨ 趣味冷知识
如果冰比水重（密度 > 1），世界会怎样？
那将是生态灾难：冰沉到水底，江河湖海从底部开始结冰，整个水体最终会冻成一块大冰块，水里的鱼和生物全部活不了。更可怕的是，即使夏天，水底的冰也很难融化——因为阳光照不到那么深。幸好水的「反常膨胀」让冰浮在水面上，形成隔热层，保护了水下生命。这就是为什么水在 4°C 密度最大这一特性被称为「生命的奇迹」。
✨ 趣味冷知识
为什么热气球能飞？
热气球内部空气被加热 → 体积膨胀（热胀冷缩） → 密度变小 → 平均密度小于外部冷空气 → 浮力大于重力 → 飞起来了！这和盐水选种的原理完全一致——只不过一个靠温度改变密度，一个靠加盐改变密度。

盐水选种 —— 「好种子沉下去，坏种子浮上来」

配好一定浓度的盐水——饱满种子密度大（ρ > ρ盐水）→ 下沉；干瘪种子/杂草种子密度小（ρ < ρ盐水）→ 上浮。

农民伯伯就靠这个简单原理筛选良种，千年之前的智慧！

🧾

混合物密度计算 —— 「不是简单平均」

两种物质混合，密度 = 总质量 ÷ 总体积

混合物的密度不能直接取两种物质密度的平均值！必须用 ρ = m总 / V总。

公式：m总 = m₁ + m₂，V总 = V₁ + V₂，ρ混合 = (m₁ + m₂) / (V₁ + V₂)。

如果两种液体的密度分别为 ρ₁ 和 ρ₂，且它们混合后体积不变化（理想情况）：

等体积混合：ρ = (ρ₁ + ρ₂) / 2（恰好是平均）。

等质量混合：ρ = 2ρ₁ρ₂ / (ρ₁ + ρ₂)（加权的调和平均）。

🍹湖水+河水混合——水温不同混合，密度也不同。利用密度差可以追踪洋流和水团运动，海洋学经常用到。
💎

密度的广泛应用 —— 「一颗密度打天下」

只靠一把天平和一个量筒，就能做这么多事

鉴别物质：测出密度，查密度表。金的密度 19.3 g/cm³，如果测出来差太多→可能是假的。

判断空心/实心：铝球测密度 < 2.7 g/cm³ → 空心。算出理论体积，减去实测体积 → 空心部分体积。

含金量鉴定：金饰品密度介于纯金和掺杂物之间，精密测密度可以估计含金量——阿基米德就是这么帮国王的。

工业分选：利用不同物质密度不同，用液体浮选法分离矿石。金矿开采就大量用到密度分选技术。

医学检查：骨密度检测可以判断骨质疏松——密度小说明骨骼疏松。CT 扫描本质上也是根据不同组织的密度差异成像。

🧾

空心还是实心？—— 三种判断方法

给你一个金属球，你如何判断它是不是空心的？

判断一个物体是空心还是实心，有以下三种经典方法：

方法做法判定标准
比密度测出物体的实际密度 ρ实测 = m/Vρ实测 < ρ理论 → 空心；ρ实测 = ρ理论 → 实心
比质量假设物体是实心的，计算理论质量 m理论 = ρ理论 × V实测m实测 < m理论 → 空心；m实测 = m理论 → 实心
比体积假设物体是实心的，计算理论体积 V理论 = m实测 / ρ理论V实测 > V理论 → 空心；V实测 = V理论 → 实心

空心部分体积：V空心 = V实测 - V理论 = V实测 - m/ρ理论。

⚽一个铁球质量 158g，体积 30cm³。铁的密度 7.9g/cm³。V理论 = 158/7.9 = 20cm³ < 30cm³ → 空心！空心体积 = 30 - 20 = 10cm³。
💎鉴定金饰：金密度 19.3g/cm³。一个标称纯金的手镯质量 96.5g，排水法测体积得 6cm³。ρ=96.5/6≈16.1g/cm³ < 19.3 → 不是纯金，可能掺了银或铜。
🌡

密度计 —— 「浮力不变，密度越大浮得越高」

为什么同一个密度计在不同液体里露出不一样多？

密度计始终漂浮在液面上——F浮 ≡ G计（自身重力不变，浮力也不变）。

由 F浮 = ρ液 g V排：浮力不变时，ρ液 越大 → 所需 V排 越小 → 密度计沉入液体的体积越小 → 露出液面越高。

刻度特点：密度计刻度"上小下大"——越往下密度值越大（因为沉得越深说明液体密度越小）。刻度线不均匀——下面的刻度间距大、上面间距小，因为 ρ 与 V排 成反比关系而非线性。

🍷酿酒厂用密度计测酒精浓度——发酵液中糖越多密度越大，酒精越多密度越小。密度计浮得越低说明酒精度越高。
🚘汽车防冻液检测——用密度计测冷却液密度判断防冻能力。密度越大乙二醇浓度越高，冰点越低。

密度计在清水 vs 盐水中

同一支密度计，在清水（ρ=1.0）中沉得深（V排大），在盐水（ρ>1.0）中浮得高（V排小）。F浮 ≡ G计 不变 → ρ液与V排成反比。刻度"上小下大"——沉得越深说明液体密度越小。

阿基米德测皇冠 —— 史上最著名的密度鉴定

「Eureka！我找到了！」——浴缸里诞生的科学突破

公元前 3 世纪，叙拉古国王希伦二世命工匠打造了一顶纯金皇冠，但怀疑工匠掺了银子。国王请阿基米德鉴定皇冠是否纯金——但不能损坏皇冠。

阿基米德苦思多日不得其解。一天在公共浴池泡澡时，他发现身体浸入水中越深、溢出的水越多——突然灵光一闪：

核心思路：金的密度（19.3g/cm³）远大于银（10.5g/cm³）。同等质量的纯金体积更小，放入水中排开的水更少。如果皇冠掺了银，同等重量下体积会更大 → 排开的水更多 → 浮力更大。

实验方法：① 取一块与皇冠等质量的纯金块；② 分别将纯金块和皇冠浸入装满水的容器中；③ 比较两者溢出的水量——皇冠溢出的水比纯金块多 → 皇冠体积更大 → 密度更小 → 掺了银！

激动的阿基米德光着身子跑上大街喊"Eureka!"（我找到了！）——这个古希腊单词至今仍是科学发现的代名词。这个实验同时奠定了浮力定律（阿基米德原理）和密度鉴定法的基础。

💡现代版皇冠鉴定：精密天平+排水法。天平称质量 → 排水法测体积 → 算密度。珠宝鉴定至今仍用这个原理——只不过设备从浴缸升级到了精密仪器。
Eureka!
👑 Tips 图示

阿基米德排水法测皇冠纯度

将皇冠浸入装满水的容器 → 溢出的水量 = 皇冠的体积。同等质量的纯金块溢出的水更少（因为金密度大、体积小）。皇冠溢水更多 → 证明体积更大 → 掺了密度小的银。不损坏皇冠一分一毫就完成了鉴定——密度+浮力的完美应用。

✨ 趣味冷知识
一克黄金能拉成多长的金丝？
一克纯金（约一粒米大小）可以锤打成面积约 1 平方米的金箔，或者拉成约 3000 米长的金丝——比两个东方明珠塔叠起来还长。金的延展性极好，但密度极大（19.3g/cm³）。利用密度可以精确鉴定黄金纯度：密度对得上就是纯金，对不上就是掺了别的金属。
✨ 趣味冷知识
地球上密度最大和最小的东西是什么？
自然界密度最大的物质是锇（osmium），密度约 22.6 g/cm³——同样体积的锇比铅还重近一倍。密度最小的固体是气凝胶（aerogel），密度仅约 0.001 g/cm³——99.8% 都是空气，被称为"固体烟雾"，可以放在蒲公英上而不压弯花丝。宇宙中密度最大的是中子星——一茶匙中子星物质重约 10 亿吨。

⚠ 常见误区提醒

  • 「质量就是重量。」 —— 纠正：质量是属性（kg），重量是力（N），G = mg。换了星球质量不变，重量变。
  • 「密度大的物体一定质量大。」 —— 纠正：一小块金子和一车棉花——金子密度大但质量小。m = ρV，和体积也有关。
  • 「密度和温度没关系。」 —— 纠正：一般物体热胀冷缩 → 质量不变体积变 → 密度改变。
  • 「冰熔化成水，质量变小。」 —— 纠正：质量不变！冰变水只是状态变了。一杯冰全化了还是一杯水（忽略蒸发）。
  • 「混合物的密度 = 两个密度的平均值。」 —— 纠正：ρ混合 = m总 / V总。只有等体积混合时才等于平均。
  • 「1 g/cm³ = 1 kg/m³。」 —— 纠正：1 g/cm³ = 1000 kg/m³。1 g/cm³ × 1000 = 1000 kg/m³。
  • 「天平只能测固体质量。」 —— 纠正：液体也能测——用「差减法」（总质量 - 容器质量）。

🧪 生活小实验：自制密度计判断盐水浓度

  1. 准备：一根吸管、一小块橡皮泥、一杯清水、盐。
  2. 吸管一端用橡皮泥封住（配重），放入清水中，记录漂浮时的水位线。
  3. 往杯里加盐搅拌溶解，再把吸管放入。
  4. 观察：吸管在盐水中浮得更高（露出的部分更多）！

原理：盐水密度大 → 同样重量的吸管排开更少体积就能浮起来 → 吃水变浅。

🧪 生活小实验：密度彩虹

  1. 准备：一个透明杯子、蜂蜜、牛奶（或洗洁精）、水、食用油、色素。
  2. 依次缓慢倒入：蜂蜜（最底）→ 牛奶 → 彩色水 → 食用油（最顶）。
  3. 每倒一种液体时沿杯壁慢慢流，避免混合。
  4. 观察：不同密度液体自动分层，形成漂亮彩虹！

原理：密度越大越下沉，密度越小越上浮。ρ蜂蜜 ≈ 1.4 > ρ牛奶 ≈ 1.03 > ρ水 = 1.0 > ρ油 ≈ 0.9（单位 g/cm³）。

🧪 生活小实验：阿基米德排水法——判断鸡蛋新鲜度

  1. 准备：一杯清水、一个新鲜鸡蛋、一个存放较久的鸡蛋。
  2. 将两个鸡蛋分别放入清水杯中。
  3. 观察：新鲜鸡蛋沉底（密度 > 1），陈鸡蛋上浮或悬浮（密度 ≈ 1 甚至 < 1）。
  4. 原因：鸡蛋存放越久，内部水分蒸发、气室变大，整体密度变小——这是阿基米德原理在家里的日常应用。
