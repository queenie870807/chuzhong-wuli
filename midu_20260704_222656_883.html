第四章🧾 密度 —— 物质的「紧凑指数」

⚖ 质量 m

  • 物体所含物质的多少
  • 单位：kg / g / t
  • 不随位置、形状改变

📦 密度公式

  • ρ = m / V
  • 1 g/cm³ = 1000 kg/m³
  • 物质特性，与 m、V 无关

🔬 测量方法

  • 规则固体：天平 + 刻度尺
  • 不规则固体：天平 + 排水法
  • 液体：天平 + 量筒

🌡 密度与温度

  • 热胀冷缩 → 密度变化
  • 水在 4℃ 密度最大
  • 反常膨胀：冰浮于水

🌱 密度应用

  • 鉴别物质（真假金银）
  • 盐水选种 / 牛奶检测
  • 判断空心 / 实心

🎁 混合物密度

  • 合金 = 总质量 ÷ 总体积
  • 不是简单取平均！
📚 核心概念
⚖

质量 —— 「你有多『多』物质」

你在月球上变轻了，但质量没变——质量是你的「物质身份证」

质量 m：物体所含物质的多少。单位：吨(t) → 千克(kg) → 克(g) → 毫克(mg)，1 t = 1000 kg。

质量是物体的固有属性：不随位置（地球/月球）、形状（捏扁橡皮泥）、状态（冰/水）改变。

🌍一个 45 kg 的女生，在月球上重力只有地球的 1/6，但质量还是 45 kg——质量不变，变的是重力。
🎂一块巧克力掰成两半，总质量不变。把它融化了再凝固，质量还是不变——物理变化不改变质量。
📦快递包裹从上海寄到北京，质量不会因为「移动了位置」就改变。质量与地理位置无关！

密度 —— 「紧凑程度的身份证」

同样大小的东西，密度大的更重。密度是物质的一种特性——一杯水和一桶水，密度一样大。

ρ = m / V
ρ = 密度 (kg/m³) m = 质量 (kg) V = 体积 (m³)

1 kg 棉花和 1 kg 铁块——质量相同，天平平衡。但棉花体积巨大（密度小），铁块一点点（密度大）。单位换算：1 g/cm³ = 1000 kg/m³（高频考点！）。水的密度 ρ水 = 1.0 × 10³ kg/m³ = 1.0 g/cm³。

✨ 趣味冷知识
为什么冰浮在水面上？
冰的密度（0.9 g/cm³）小于水的密度（1.0 g/cm³）——这在自然界非常罕见！大多数物质固态密度大于液态。水在 4℃ 时密度最大，结冰后反而膨胀变轻了，所以冰浮在水面。这也保护了水下的生物——冰层像个「保温盖」，让下面的水不会完全冻住。
✨ 趣味冷知识
地球内部密度有多大？
地壳岩石密度约 2.7 g/cm³，但地球核心（主要由铁和镍组成）密度高达 13 g/cm³——是水的 13 倍！一勺地核物质在地球表面重量可达 130 克。地球平均密度约 5.5 g/cm³，是太阳系中密度最大的行星。

密度测量 —— 天平 + 量筒「黄金搭档」

不规则固体（如石头）：

① 天平测质量 m → ② 量筒装水读体积 V₁ → ③ 石头浸没，读 V₂ → ④ 体积 V = V₂ - V₁（排水法） → ⑤ ρ = m / (V₂-V₁)

液体（如盐水）：测空烧杯 m₁ → 倒液体测总 m₂ → m液 = m₂ - m₁ → 量筒测 V → ρ = m液 / V

规则固体：天平测 m → 刻度尺量长宽高算 V → ρ = m/V

👑阿基米德鉴定王冠：浸入水中测 V排 → 天平测质量 → 算密度与纯金对比 → 发现掺了银！

密度与温度 —— 「热胀冷缩的秘密」

一般物质热胀冷缩：温度升高 → 体积膨胀 → 质量不变 → 密度变小。

上方分子间隔大 → 高温时密度小。下方分子间隔小 → 低温时密度大。

水的反常：4℃ 以上热胀冷缩（正常），但 4℃ → 0℃ 反而冷胀热缩！所以 4℃ 的水密度最大，沉在最底下。冬天湖面结冰了，底层还是 4℃ 的水，鱼儿才能活下来。

🌊夏天在游泳池：上层水被太阳晒热，密度小；下层水凉，密度大。所以越往下越冷！
🌱

密度应用 —— 「生活中无处不在」

从农田到餐桌，密度一直在「悄悄工作」

盐水选种：调好一定密度的盐水 → 饱满种子（密度大）沉底，瘪种子（密度小）浮起 → 轻松分离！农民伯伯自古就用这个办法。

牛奶检测：纯牛奶密度约 1.03 g/cm³。掺水后密度下降 → 用密度计一测就知道有没有掺水。

鉴别物质：测出密度后查密度表 → 是金是铜一测便知。纯金密度 19.3 g/cm³，铜只有 8.9 g/cm³。

判断空心/实心：算出实际密度 < 理论密度 → 空心！比如一个铁球实际密度 5 g/cm³ < 铁的理论密度 7.9 g/cm³ → 空心。

⛽加油站的汽油和柴油密度不同（汽油约 0.7 g/cm³，柴油约 0.85 g/cm³），密度计也是加油站检测油品的重要工具。
🍹鸡尾酒分层：密度大的糖浆在底层，密度中的果汁在中层，密度小的酒精在上层——这是密度分层的艺术！
🎁

混合物密度 —— 「不是简单平均」

合金的密度要看总质量和总体积

混合物的密度 = 总质量 ÷ 总体积。千万不能简单取两种密度的算术平均值！

ρ混 = (m₁ + m₂) / (V₁ + V₂)
m₁、m₂ = 各组分质量 V₁、V₂ = 各组分体积

例：1 kg 金（ρ=19.3）和 1 kg 银（ρ=10.5）混在一起 → 总体积 = 1/19.3 + 1/10.5 ≈ 0.147 dm³ → ρ混 = 2 ÷ 0.147 ≈ 13.6 g/cm³，而不是 (19.3+10.5)/2 = 14.9！

💰古代造假金币：在金里掺银，颜色差别不大但密度变了。用阿基米德的方法一测密度就能识破！
✨ 趣味冷知识
世界上最「轻」的固体有多轻？
气凝胶（aerogel）被称为「冻结的烟」，密度仅约 1.9 mg/cm³——只有空气密度的 1.5 倍！一块砖头大小的气凝胶重量不到 2 克，却能承受自身重量几千倍的压力。它被用在航天器上捕获太空尘埃，吉尼斯认证为「密度最小的固体」。

⚠ 常见误区提醒

  • 「密度与质量成正比、与体积成反比。」 —— 纠正：密度是物质特性，与 m、V 无关。一杯水和一桶水密度一样大。
  • 「物体的质量在月球上会变小。」 —— 纠正：质量不变！变的是重力（因为 g 值不同）。质量是固有属性。
  • 「冰的密度大于水。」 —— 纠正：冰 0.9 < 水 1.0，所以冰浮在水面。水在 4℃ 密度最大。
  • 「合金密度 = 各金属密度的平均值。」 —— 纠正：合金密度 = 总质量 ÷ 总体积，不同体积比例结果不同。
  • 「温度变高，所有物质的密度都变小。」 —— 纠正：水在 0~4℃ 是例外——温度升高密度反而增大（反常膨胀）。
  • 「量筒可以直接测固体体积。」 —— 纠正：只有沉入水中的固体才能用排水法。漂浮的要用「针压法」或「助沉法」。

🧪 生活小实验：彩虹密度塔

  1. 准备：透明杯子、蜂蜜、洗洁精、水、食用油、食用色素。
  2. 在水中滴入色素染色（让分层更明显）。
  3. 沿杯壁缓慢倒入蜂蜜 → 染色洗洁精 → 染色水 → 食用油，每层都要慢慢倒。
  4. 观察：四种液体分层排列，像彩虹塔！

原理：不同液体密度不同（蜂蜜 > 洗洁精 > 水 > 油），密度大的沉在下面，密度小的浮在上面。

🧪 生活小实验：自制盐水选种

  1. 准备：一杯清水、盐、一个鸡蛋。
  2. 鸡蛋放入清水 → 沉底（鸡蛋密度 > 清水密度）。
  3. 不断加盐搅拌，直到鸡蛋刚好悬浮在水中。
  4. 此时：盐水密度 = 鸡蛋密度。再多加一点盐 → 鸡蛋浮起！

原理：盐水密度随盐浓度增大，当盐水密度超过鸡蛋密度时，鸡蛋上浮。这和盐水选种是同一个道理！

🧪 趣味问答

Q：1 kg 棉花和 1 kg 铁，哪个密度大？哪个质量大？
A：质量一样大（都是 1 kg）。但铁的密度大——所以铁的体积小很多。这就是为什么同样 1 kg，棉花占一大袋，铁才一小块。
Q：如果把一块木头从地球带到月球，它的质量和密度会变吗？
A：质量不变（物质多少没变）。体积也不变（木头没有热胀冷缩）。所以密度 = 质量/体积，也不变！变的只是重力。
