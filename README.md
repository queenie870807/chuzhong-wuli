# 初中物理知识手册

面向初中生的**物理知识学习网站**，卡通风设计，共 8 个章节，每章配 50 题测验。

## 内容结构

| 章节 | 文件 | 说明 |
|---|---|---|
| 首页 | `index.html` | 总览导航 |
| 声现象 | `sheng.html` + `sheng-quiz.html` | 声的产生、传播、特性 |
| 光现象 | `guang.html` + `guang-quiz.html` | 光的反射/折射、透镜 |
| 热学 | `re.html` + `re-quiz.html` | 温度、物态变化、内能 |
| 电学 | `dian.html` + `dian-quiz.html` | 电路、欧姆定律、电功率 |
| 密度 | `midu.html` + `midu-quiz.html` | 质量与密度 |
| 压强 | `yaqiang.html` + `yaqiang-quiz.html` | 固体/液体/大气压强 |
| 运动 | `yundong.html` + `yundong-quiz.html` | 机械运动 |
| 机械 | `jixie.html` + `jixie-quiz.html` | 简单机械、功和能 |
| 中考攻略 | `zhongkao.html` | 命题方向、答题技巧 |
| 模拟真题 | `zhenti1.html` / `zhenti2.html` | 2023 / 2024 两套 |

## 技术说明

- 纯 HTML + CSS（`style.css`），无框架、无外部依赖，双击 `index.html` 即可离线使用
- 设计风格：柔粉 / 薄荷绿 / 天空蓝卡通风，面向初中女生
- 内容紧扣上海中考考纲，含中考命题方向与易错题集
