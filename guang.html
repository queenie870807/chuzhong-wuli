📚 核心概念
💡

光的直线传播

光在同种均匀介质中沿直线传播

光在同一种均匀介质中沿直线传播。影子的形成、日食月食、小孔成像都是光的直线传播的应用。

光在真空中速度：c = 3 × 10⁸ m/s——宇宙中最快的速度！光在空气中的速度略小于真空但相差不大。

🔊

光的反射定律

三线共面、两线分居、两角相等

反射定律：反射光线、入射光线和法线在同一平面内；反射光线和入射光线分居法线两侧；反射角等于入射角。

光路可逆性：如果光线逆着反射光线的方向射入，它会逆着入射光线的方向射出。你从镜子看到别人，别人也能从镜子看到你——就是这个原理。

🔬

镜面反射 vs 漫反射

为什么黑板会"反光"？

类型表面特征反射特点现象
镜面反射光滑表面（镜子、平静水面）平行入射 → 平行反射特定角度看到耀眼反光，其他角度看不见
漫反射粗糙表面（纸、墙壁、黑板）平行入射 → 向各个方向反射从任何角度都能看到物体

关键理解：漫反射中每一条光线仍然遵守反射定律！只是表面微观凹凸不平，导致法线方向各不相同，反射光就四面八散了。没有漫反射，世界将一片漆黑——因为你只能看到恰好把光反射到你眼睛里的那个方向。

📕黑板"反光"——光滑黑板的镜面反射使坐在特定角度的同学看不清字。解决方法：用粗糙的黑板（漫反射）或调整坐的位置。
🔬 Tips 图示

镜面反射（左）vs 漫反射（右）

三束平行光照到镜面（左）——反射光仍然平行，只在特定方向看到。照到粗糙表面（右）——反射光四散开来，无论站在哪个角度都能看到物体。记住：漫反射依然遵守反射定律！

🌈

光的折射规律

光从一种介质斜射入另一种介质时，传播方向发生偏折

光从空气斜射入水中或其他介质中时，折射光线向法线方向偏折（折射角 < 入射角）。反之，从水中射向空气时，折射光线远离法线。

🌊筷子放入水中看起来"弯折"——筷子反射的光从水中进入空气时发生折射，眼睛逆着光线看去，筷子就变"弯"了。
🏝海市蜃楼——热空气和冷空气密度不同，光在其中不断折射，远处的景物被投射到空中，形成"空中楼阁"的幻象。

凸透镜成像 —— 完整规律表

物距 u 决定了一切

物距(u)像的性质像距(v)应用记忆口诀
u > 2f倒立、缩小、实像f < v < 2f照相机"远照小"
u = 2f倒立、等大、实像v = 2f测焦距"二倍等"
f < u < 2f倒立、放大、实像v > 2f投影仪"近放大"
u = f不成像—平行光源"焦点无"
u < f正立、放大、虚像|v| > u放大镜"近镜虚"

成像规律的两个分界点：

· 焦点 F（u = f）——实像与虚像的分界点（u > f 成实像，u < f 成虚像）

· 二倍焦距 2f（u = 2f）——放大与缩小的分界点（u > 2f 缩小，u < 2f 放大）

实像 vs 虚像：实像——实际光线汇聚而成，能用光屏承接（照相机、投影仪）；虚像——光线的反向延长线汇聚而成，不能用光屏承接（放大镜）。

眼睛与视力矫正

你的眼睛就是一个自带变焦的凸透镜

正常眼睛：晶状体（凸透镜）将远处物体成像在视网膜上。睫状肌调节晶状体曲率来"变焦"——看远处时晶状体变薄，看近处时变厚。

类型成因成像位置矫正镜片矫正原理
近视眼晶状体太厚/眼球太长像落在视网膜前凹透镜凹透镜使光发散，像后移到视网膜
远视眼晶状体太薄/眼球太短像落在视网膜后凸透镜凸透镜使光会聚，像前移到视网膜
👓近视眼看远处模糊——为什么？远处物体在近视眼中成像在视网膜前方，光到了视网膜上已经发散开。戴凹透镜发散光线，把像后推到视网膜上。

看不见的光 —— 红外线与紫外线

光谱两端还有两个不为人知的"隐形推手"

1800 年，英国天文学家赫歇尔用温度计测量光谱各处的温度，发现在红光外侧温度更高——发现了红外线。1801 年，里特发现紫光外侧的化学物质变黑更快——发现了紫外线。

特性红外线紫外线
频率范围低于红光（不可见）高于紫光（不可见）
显著效应热效应（任何有温度的物体都在发射红外线）化学效应（使荧光物质发光、杀菌）
主要应用红外遥控、夜视仪、红外测温、热成像杀菌消毒、验钞（荧光）、促进维生素D合成
危害过量红外辐射可灼伤皮肤过量暴晒导致皮肤癌、白内障
📷手机遥控器——前端那个小灯泡发出的是红外线，肉眼看不见但手机摄像头能拍到（红外线可以穿过手机相机的红外滤光片被传感器捕捉到）。试试用手机摄像头拍遥控器前端！
🏥医院用紫外线灯消毒——紫外线能破坏细菌和病毒的 DNA，高效杀菌。但紫外线灯开启时人必须离开，否则会灼伤眼睛和皮肤。
白光 → 七色光谱
🌈 Tips 图示

三棱镜色散：白光 = 七色光的混合

一束白光（左侧）穿过三棱镜后，不同颜色的光折射角度不同——红光折射最小，紫光折射最大——白光被分解成红、橙、黄、绿、蓝、靛、紫七色光带。彩虹就是大自然的三棱镜实验。

✨ 趣味冷知识
天空为什么是蓝色的？
太阳光穿过大气层时，蓝色光波长短，最容易被空气中的微小粒子散射（瑞利散射）。所以我们抬头看到的天空，是各个方向散射过来的蓝光。傍晚太阳接近地平线时光线穿过更厚大气层，蓝光被散射殆尽，红光占主导——所以夕阳是红色的。
✨ 趣味冷知识
彩虹为什么是弧形的？
彩虹是太阳光在水滴中折射-反射-折射后形成的。每个水滴像一个微型三棱镜，把白光分解成七色。所有满足特定角度的水滴排列成一个圆形光环——我们在地面只能看到半圆（地平线以下被挡住了）。坐飞机时能看到完整的圆形彩虹！
✨ 趣味冷知识
猫的眼睛为什么在黑暗中发光？
猫眼视网膜后面有一层叫"照膜"（tapetum lucidum）的反射层，能把穿过视网膜的光再反射回来，让感光细胞"二次利用"光线，极大的增强了夜视能力。你看到的"发光"其实是照膜反射回来的光——和反射定律有关！
✨ 趣味冷知识
变色龙变色是伪装吗？
变色龙的皮肤里有特殊的纳米晶体，通过调整晶格间距来反射不同波长的光——本质上是利用光的干涉和反射。但变色主要不是为了伪装——而是为了调节体温和社交沟通！

⚠ 常见误区提醒

  • ❌ "漫反射不遵守反射定律" → ✅ 漫反射中每一条光线仍然遵守反射定律！只是表面微观法线方向不同。这是考试高频陷阱。
  • ❌ "实像可以用眼睛直接看到，虚像不行" → ✅ 虚像也能用眼睛看到！镜子里的虚像你难道看不见吗？区别在于实像能用光屏承接，虚像不能。
  • ❌ "凸透镜一定成放大的像" → ✅ 不一定！u > 2f 时成缩小的像（照相机原理）。只有 u < f 时才成放大虚像。
  • ❌ "光从空气进入水中速度不变" → ✅ 光在不同介质中速度不同。水中光速约为真空中 3/4，玻璃中约为 2/3。正因为速度变了才发生折射。
  • ❌ "近视眼戴凸透镜" → ✅ 大错特错！近视眼看远处模糊是因为像在视网膜前，需要用凹透镜发散光线把像后移。

🧪 家庭小实验：小孔成像

  1. 找一个纸杯，底部扎一个小针孔。杯口蒙上薄纸（描图纸/蜡纸）。
  2. 在暗房间里，杯底对着窗外明亮景物（或蜡烛）。
  3. 观察杯口薄纸上的影像——倒立的！
  4. 思考：为什么是倒立的？（光的直线传播——上方光线穿过小孔打在下方）

🧪 家庭小实验：自制放大镜

  1. 在透明塑料袋中装少许水，扎紧袋口形成一个球状水珠。
  2. 透过水珠看报纸上的小字——字被放大了！
  3. 这就是凸透镜原理——水珠相当于一个简易凸透镜。

🧪 家庭小实验：在家里造彩虹

  1. 晴天下午，在窗边放一盆水。
  2. 拿一面镜子斜放入水中，让阳光照在镜子上。
  3. 调整镜子角度，在天花板或墙上寻找彩虹！

原理：阳光穿过水面产生折射，被镜子反射回来——相当于大自然的三棱镜色散实验。

2024年上海中考 · 作图题 · 3分 — 光的反射
如图所示，入射光线AO与平面镜MN的夹角为30°，请画出反射光线，并标出反射角的大小。
🔎 解题思路
  1. 画法线：过入射点O作镜面的垂线（法线）。法线用虚线。
  2. 求入射角：入射角是入射光线与法线的夹角（不是与镜面的夹角！）。AO与镜面夹角30° → 入射角 = 90° - 30° = 60°。
  3. 反射角 = 入射角：反射角 = 60°。在法线另一侧画出反射光线，使反射角 = 60°。
  4. 标注：给反射光线画箭头，标注反射角60°。
✅ 答案：反射角 = 60°（入射角=60°，反射角=60°）
⚠ 易错陷阱：入射角是入射光线与法线的夹角，不是与镜面的夹角！题目给的是"与镜面夹角30°"，必须先算出入射角=90°-30°=60°，再得反射角=60°。直接写30°的同学——小心这个经典陷阱。

2023年上海中考 · 选择题 · 2分 — 光的折射
一束光线从空气斜射入水中，入射角为45°，则折射角（ ）
🔎 解题思路
  1. 折射规律：光从空气进入水（从疏介质进入密介质），折射光线向法线偏折，折射角 < 入射角。
  2. 入射角=45° → 折射角必定 < 45°。
  3. 反向：如果光从水进入空气（密→疏），折射光线偏离法线，折射角 > 入射角。
  4. 记忆口诀："空气大角"——不管入射还是折射，在空气中的那个角更大。
✅ 答案：小于45°（折射角<入射角）
⚠ 易错陷阱：光从空气进入水，折射角<入射角；光从水进入空气，折射角>入射角。不要记反！可以用"空气角大"记忆，或者想筷子插入水中看起来"折断"了——是水中的部分看起来向上偏折，说明折射角变小。

2022年上海中考 · 选择题 · 2分 — 视力矫正
近视眼患者看远处物体时，像成在视网膜的（ ），应佩戴（ ）矫正。
🔎 解题思路
  1. 近视眼成因：晶状体曲度太大（太凸），折光能力太强，远处物体成像在视网膜前方。
  2. 矫正方法：需要让光线先发散再进入眼睛→佩戴凹透镜（发散透镜）。
  3. 远视眼对比：晶状体曲度太小，近处物体成像在视网膜后方→佩戴凸透镜（会聚透镜）。
  4. 记忆口诀："近凹远凸"——近视戴凹透镜，远视戴凸透镜。
✅ 答案：前方；凹透镜
⚠ 易错陷阱：近视眼是像成在视网膜前方（不是后方！）——因为晶状体太凸了，光线提前会聚。很多同学记反了近视和远视的成像位置。记法：近视眼看不清远处→光线"超前"汇聚→戴凹透镜发散回来。

易错题 1 — 反射角判断
入射光线与镜面的夹角为25°，则反射角为（ ）
A. 25° B. 65° C. 50° D. 155°
✅ 正确答案：B
错误选项分析：这是反射最经典的陷阱！入射角=90°-25°=65°，反射角=入射角=65°。选A的同学直接把"与镜面的夹角"当成了入射角——入射角必须是与法线的夹角。
易错题 2 — 平面镜成像
某人站在平面镜前1m处，他在镜中的像距他本人（ ）
A. 0.5m B. 1m C. 2m D. 无法确定
✅ 正确答案：C
错误选项分析：物距=1m → 像距=1m（像到镜面距离=物到镜面距离）。但问题问的是"像距他本人"——是像到人的距离 = 物距 + 像距 = 1+1 = 2m。

🧪 探究凸透镜成像规律

上海中考最高频实验——近3年连续出现，分值4~5分

🛠 实验器材
  • 光具座（带刻度）
  • 凸透镜（已知焦距，如f=10cm）
  • 蜡烛（或LED光源）
  • 光屏
  • 火柴（或打火机）
📝 实验步骤
  • 步骤1：将凸透镜固定在光具座中间，蜡烛和光屏分别放在两侧。调整三者中心在同一高度（使像成在光屏中央）。
  • 步骤2：将蜡烛移至u>2f处（如30cm处），移动光屏找到最清晰的像，记录像的性质（倒立/缩小/实像）和像距。
  • 步骤3：将蜡烛移至f
  • 步骤4：将蜡烛移至u
  • 步骤5：将蜡烛移至u=2f和u=f处，验证特殊位置的成像规律。
🔬 实验原理与结论
  • 原理：凸透镜成像规律由 1/f = 1/u + 1/v 决定。像的性质取决于物距u与焦距f的关系。
  • 关键口诀："一倍焦距分虚实，二倍焦距分大小；物近像远像变大，物远像近像变小"。
  • 实像与虚像判断：u>f→实像（光屏可接收）；u
🔎 考试常见设问
  1. "为什么要调整烛焰、透镜、光屏三者中心在同一高度？"——使烛焰的像能完整地成在光屏中央，否则像会偏高或偏低，甚至偏出光屏范围。
  2. "如果光屏上的像偏上，应如何调节？"——将蜡烛向上移，或将透镜和光屏同时向下移（像偏向哪里，物体就往哪里移）。
  3. "u=f时为什么光屏上没有像？"——折射光线是平行光（不汇聚），所以无法在光屏上成像。这是凸透镜成像的"盲点"。
  4. "若透镜被遮住一半，像会怎样？"——像依然完整，但亮度变暗。因为每个点发出的光仍有一部分通过透镜成像，只是光量减半。
  5. "当蜡烛燃烧变短时，光屏上的像如何移动？"——像向上移动。因为光源中心降低了，像的位置会向相反方向偏移。
