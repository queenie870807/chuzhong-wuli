📚 核心概念
📦

压强 —— 「压力有多集中？」

同样的力，面积越小压强越大

p = F / S
p 压强 (Pa) F 压力 (N) S 受力面积 (m²)

1 Pa = 1 N/m²。一张报纸平铺在桌面上产生的压强约为 1 Pa。

增大压强：增大压力或减小受力面积（刀刃锋利、针尖细）。减小压强：减小压力或增大受力面积（滑雪板、坦克履带）。

🌊

液体压强 —— 「越深越压」

只跟深度和液体密度有关

p = ρ g h
p 压强 (Pa) ρ 液体密度 (kg/m³) h 深度 (m)

液体压强与容器形状无关——U形管两侧液面高度差由压强差决定，与管径粗细无关。这就是连通器原理。

🌑

帕斯卡原理 —— 四两拨千斤

加在密闭液体上的压强，能大小不变地向各个方向传递

液压机原理：小活塞上施加较小的力，通过液体压强传递，大活塞上产生巨大的力——F₁/S₁ = F₂/S₂

🛠汽车修理厂的液压千斤顶——一个成年人用手力就能顶起一辆小汽车。小活塞面积是大活塞面积的 1/100，力就放大 100 倍！
F₁小
F₂大
P 不变：F₁/S₁ = F₂/S₂

帕斯卡原理——液压机

小活塞面积小，施加很小的力 F₁ 就能产生足够的压强 P。液体压强大小不变地传到各处——大活塞面积大，P × S₂ = 巨大的 F₂。这就是"四两拨千斤"的物理学基础。

🌎

大气压强 —— 空气的"重量"

你身上压着约 10 吨的空气——但你完全感觉不到

标准大气压：1 atm = 1.013 × 10⁵ Pa ≈ 760 mmHg = 10.34 m 水柱。

马德堡半球实验：两个半球合拢抽空气后，16 匹马都拉不开——大气压强的威力惊人。

🌎

托里拆利实验 —— 「称出空气的重量」

1643年，人类第一次测量了大气压强

实验过程：取一根长约 1m、一端封闭的玻璃管，灌满水银。用手指堵住开口端倒插入水银槽中，松开手指——管中水银柱下降到约 760mm（76cm）高度后停止下降。

原理解释：管顶部分形成真空（"托里拆利真空"）。管外水银槽面受到大气压强 P₀，管内水银柱产生的压强 P = ρgh。平衡时：P₀ = ρgh——大气压强等于 760mm 水银柱产生的压强。

为什么用水银不用水？水的密度只有水银的 1/13.6，如果用水做实验，水柱高度将达到 10.34m——需要三层楼高的玻璃管！水银密度大，让实验变得切实可行。

影响因素：水银柱高度随海拔升高而降低（大气变稀薄）、随天气变化而波动（晴天高压、阴天低压）。这就是气压计的原理。管子的粗细、倾斜角度不影响水银柱的竖直高度——只与大气压有关。

⛰在海拔 3000m 的高原上做托里拆利实验，水银柱只有约 53cm——因为那里的大气压只有海平面的约 70%。

托里拆利实验——首次测量大气压强

1643年，托里拆利将一端封闭的玻璃管灌满水银，倒插入水银槽。管中水银柱下降到约 76cm 高度——这个高度对应的压强就是大气压强。管顶的"真空"（托里拆利真空）是历史上第一个人工真空。水银柱高度随天气和海拔变化——气压计的原理。

✈

流体压强与流速 —— 伯努利原理

流速大的地方压强小——飞机为什么能飞？

伯努利原理：在流体（气体或液体）中，流速越大的位置压强越小。

飞机升力原理：机翼上表面弧度大——气流经过上表面的路程比下表面长，在相同时间内上表面气流速度更快。根据伯努利原理：上表面压强小，下表面压强大——产生向上的升力。

🏦站台黄色安全线——火车高速驶过时，火车与站台之间的空气流速极大，压强极小。如果人站得太近，会被"吸"向火车——非常危险！
💨喷雾器——快速气流通过细管口时压强变小，瓶内液体被大气压"压"上来，被气流吹成雾状喷出。
⚽香蕉球（足球弧线球）——踢球时让球旋转，一侧气流速度快（压强小）、一侧慢（压强大），足球在空中拐弯——伯努利原理+马格努斯效应。
流速快 → 压强小
流速慢 → 压强大
✈ Tips 图示

飞机机翼升力——伯努利原理

机翼上表面弧度大：气流路程长 → 流速快 → 压强小。下表面平直：气流路程短 → 流速慢 → 压强大。下表面压强 > 上表面压强，产生向上的升力。飞得越快升力越大——这就是飞机需要跑道加速才能起飞的原因。

🐳

浮力 —— 阿基米德的"尤里卡"时刻

浸在液体中的物体受到向上的浮力

F浮 = G排 = ρ液 g V排

阿基米德原理：浸在液体中的物体受到的浮力等于它排开的液体受到的重力。注意：浮力只与液体密度和排开液体的体积有关——与物体本身的密度、形状、浸入深度无关！

✨ 名场面
阿基米德在浴缸里发现了浮力原理，激动得光着身子跑上大街喊"Eureka!"（我找到了！）。国王的皇冠是否掺了银——金比银密度大。同等重量，纯金体积更小，放入水中排开的水更少，浮力更小——就是这个思路判断出了掺假。

物体是上浮、下沉、悬浮还是漂浮？

状态F浮 vs G物ρ液 vs ρ物V排 vs V物例子
下沉F浮 < G物ρ液 < ρ物V排 = V物石头沉入水底
悬浮F浮 = G物ρ液 = ρ物V排 = V物潜水艇悬停

🌋死海——含盐量极高，ρ液非常大。人躺在上面不会下沉——因为人体密度小于死海水密度，浮力等于体重时 V排 很小，人浮在水面上。
🌡

密度计原理 —— 「越稠浮得越高」

同一个密度计在不同液体中漂浮——液面位置揭示了密度

密度计始终漂浮在液面上——F浮 = G计（重力不变，浮力也不变）。根据 F浮 = ρ液 g V排，浮力不变时：ρ液越大 → V排 越小 → 密度计露出液面越高。

所以说：密度计在密度大的液体中浮得高！刻度是"上小下大"——越往下刻度值越大。

🍷酿酒厂用密度计测酒精浓度——发酵液中糖越多密度越大，酒精越多密度越小。密度计浮得低说明酒精度高！
🚘汽车防冻液检测——用密度计测冷却液的密度判断防冻能力，密度越大冰点越低。

✨ 趣味冷知识
马德堡半球——16匹马都拉不开两个半球
1654年，德国马德堡市长奥托·冯·居里克把两个铜制半球合拢，抽掉里面的空气——大气压强让两个半球紧紧贴在一起。16匹马（每边8匹）都拉不开。这不是因为半球本身有多牢固——是看不见摸不着的大气压强在做功：约 100000 N/m² × 半球截面 ≈ 数万牛顿的力！
✨ 趣味冷知识
潜水艇如何自由沉浮？
潜艇有压载水舱。进水 → 自重增加 → G > F浮 → 下沉。用压缩空气排出水 → 自重减小 → G < F浮 → 上浮。精确控制进水量可悬停在任何深度。注意：改变的是自重而不是浮力——与密度计原理完全不同。
✨ 趣味冷知识
一头大象站在一根针上，哪个压强大？
针尖对地面的压强大得多！大象虽重（4000kg ≈ 40000N），但四脚面积很大（约 1m²），压强仅约 40000 Pa。针尖面积约 0.0000001 m²——即使只用 0.1N 的力，压强也高达 10⁶ Pa——是大象的 25000 倍！这就是为什么针能轻易刺穿东西。
✨ 趣味冷知识
为什么高山上煮不熟饭？
海拔越高气压越低，水的沸点也越低。在海拔 5000m 的高原上，水 85°C 就沸腾了——但 85°C 不足以煮熟米饭和肉类。这就是为什么登山者必须带高压锅：高压锅增大内部气压 → 提高沸点到 120°C 以上 → 食物才能煮熟。气压、沸点、烹饪——三者紧密相连。
✨ 趣味冷知识
船为什么能浮在水面上？——铁船的秘密
一块实心铁会沉入水底，但万吨巨轮也是铁做的却能浮着。关键在于轮船是"空心"的——巨大的船体排开了巨量海水。根据阿基米德原理，只要排开的海水重量 ≥ 船的总重，船就能漂浮。现代最大的货轮排水量超过 40 万吨——它排开的海水体积相当于 16 个奥运会游泳池。阿基米德如果看到今天的巨轮，一定会再喊一声"Eureka！"

📖 真题精讲 上海中考真题逐题拆解
1
2023年上海中考 · 计算题 · 3分 — 压强
一个质量为2kg的铁块放在水平桌面上，铁块与桌面的接触面积为0.002m²。求：（1）铁块对桌面的压力；（2）铁块对桌面的压强。（g取10N/kg）
🔎 解题思路
  1. 求压力：水平面上，压力=重力：F = G = mg = 2×10 = 20N。
  2. 求压强：p = F / S = 20 / 0.002 = 10,000 Pa = 1×10⁴ Pa。
  3. 注意：只有水平面时压力才等于重力！如果是斜面，压力 < 重力。
✅ 答案：（1）20N；（2）1×10⁴ Pa（或10kPa）
⚠ 易错陷阱：单位换算！面积 0.002m² = 20cm²，如果题目给的是 cm²，必须先换算成 m² 再代入公式。很多同学直接用 cm² 算，结果差10000倍。
2
2024年上海中考 · 选择题 · 3分 — 浮力
将同一个鸡蛋先后放入甲、乙两杯不同密度的盐水中。鸡蛋在甲杯中沉底，在乙杯中悬浮。下列说法正确的是（ ）
A. 鸡蛋在甲杯中受到的浮力大
B. 甲杯中盐水密度大于乙杯
C. 鸡蛋在乙杯中受到的浮力等于重力
D. 两杯中鸡蛋受到的浮力一样大
🔎 解题思路
  1. 甲杯（沉底）：F浮 < G蛋。V排 = V蛋（全部浸没）。
  2. 乙杯（悬浮）：F浮 = G蛋。V排 = V蛋。ρ液 = ρ蛋。
  3. 对比：乙杯浮力=重力 > 甲杯浮力（因为甲杯浮力<重力）。甲杯ρ液 < ρ蛋，乙杯ρ液 = ρ蛋，所以乙杯密度更大。
  4. C正确——悬浮时F浮=G。
✅ 正确答案：C
⚠ 易错陷阱：有同学认为沉底时浮力更大（因为"沉得深"）。浮力与深度无关！沉底和悬浮 V排 相同，但沉底时液体密度更小，所以浮力反而更小。
3
2022年上海中考 · 实验题 · 4分 — 浮力
在"验证阿基米德原理"实验中，小明用弹簧测力计测出石块在空气中的重力为4N，浸没在水中时弹簧测力计示数为2.5N，用溢水杯收集排开的水，测得排开水的重力为1.5N。请回答：（1）石块受到的浮力是多少？（2）实验结论是否验证了阿基米德原理？为什么？
🔎 解题思路
  1. 称重法求浮力：F浮 = G - F示 = 4 - 2.5 = 1.5N。
  2. 阿基米德原理：F浮 = G排。实验中G排 = 1.5N，F浮 = 1.5N → 相等！
  3. 结论：验证成功——浸在液体中的物体受到的浮力等于它排开液体的重力。
  4. 注意：如果数据有偏差，需分析误差来源（溢水杯中的水未满、石块取出时带出水等）。
✅ 答案：（1）1.5N；（2）验证成功，因为 F浮 = G排 = 1.5N，符合阿基米德原理。
⚠ 易错陷阱：称重法公式不能写错——F浮 = G - F示，不是 F示 - G。弹簧测力计在水中示数变小，减小的值就是浮力。另一个易错点：溢水杯必须装满水（至溢水口），否则排开的水不能完全收集。
📌 易错题集 5道高频易错选择题
易错题 1 — 压强与压力区分
关于压力和压强，下列说法正确的是（ ）
A. 压力越大，压强一定越大 B. 压强是表示压力作用效果的物理量 C. 受力面积越大，压强一定越小 D. 压力就是重力
✅ 正确答案：B
错误选项分析：A——p=F/S，压力大但如果受力面积也大，压强不一定大。C——同理，受力面积大但压力也大则压强不一定小。D——压力不一定等于重力（斜面、侧壁等）。压强是压力的集中程度。
易错题 2 — 液体压强理解
三个底面积相同但形状不同的容器（柱形、上宽下窄、上窄下宽），装相同深度的水，比较容器底部受到的压强（ ）
A. 柱形容器底部压强最大 B. 上宽下窄容器底部压强最大 C. 三个容器底部压强一样大 D. 上窄下宽容器底部压强最大
✅ 正确答案：C
错误选项分析：液体压强 p=ρgh，只与液体密度和深度有关，与容器形状无关。三个容器水深度相同，底部压强相同。但注意：底部压力（F=pS）相同，而桌面受到的压力（总重）则不同——这是两个不同的概念。
易错题 3 — 浮力与深度
一块石头从水面开始匀速下沉到水底的过程中，它受到的浮力（ ）
A. 逐渐变大 B. 逐渐变小 C. 先变大后不变 D. 始终不变
✅ 正确答案：C
错误选项分析：石头从水面到完全浸没之前，V排逐渐增大 → 浮力逐渐变大。完全浸没后，V排=V石不变 → 浮力不变（与深度无关）。选A的同学忽略了"完全浸没后"浮力不再变化。
易错题 4 — 漂浮与悬浮混淆
关于漂浮和悬浮，下列说法正确的是（ ）
A. 漂浮时浮力大于重力 B. 漂浮和悬浮时浮力都等于重力 C. 漂浮时 V排 = V物 D. 悬浮时物体部分露出液面
✅ 正确答案：B
错误选项分析：A——漂浮和悬浮都是静止状态，合力为零，F浮=G。C——漂浮时V排 < V物（部分浸入），悬浮时V排=V物（全部浸没）。D——悬浮时物体全部浸没在液体中，不露出液面。漂浮和悬浮的共同点：F浮=G；不同点：V排不同。
易错题 5 — 浮力与液体压强综合
将一木块投入水中，木块漂浮。向水中加盐使盐水密度增大，木块最终（ ）
A. 下沉一些 B. 上浮一些（露出更多） C. 浮力变大 D. 沉入水底
✅ 正确答案：B

🧪 实验探究 中考必考实验

🧪 验证阿基米德原理（探究浮力大小）

上海中考核心实验——近3年每年必考，分值3~4分

🛠 实验器材
  • 弹簧测力计（量程0~5N）
  • 金属块（或石块）
  • 溢水杯、小烧杯（收集排开的水）
  • 细线
📝 实验步骤
  • 步骤1：用弹簧测力计测出金属块在空气中的重力 G。
  • 步骤2：将溢水杯装满水（至溢水口），把小烧杯放在溢水口下方。
  • 步骤3：将金属块缓慢浸没在水中，读出此时弹簧测力计示数 F示，同时用小烧杯接住溢出的水。
  • 步骤4：用弹簧测力计测出小烧杯和排开水的总重力，减去空烧杯重力，得到排开水的重力 G排。
  • 步骤5：比较 F浮（= G - F示）与 G排 是否相等。
🔬 实验原理与结论
  • 原理：称重法 F浮 = G - F示，排液法 G排 = G总 - G杯。验证 F浮 = G排。
  • 结论：浸在液体中的物体受到向上的浮力，浮力的大小等于它排开的液体受到的重力。即 F浮 = G排 = ρ液 g V排。
🔎 考试常见设问
  1. "溢水杯中的水为什么必须装满至溢水口？"——如果水未满，金属块浸入后水面先上升到溢水口才溢出，导致收集的排水量偏少，G排偏小，实验失败。
  2. "如果先测空烧杯重力，再测烧杯+水的重力，顺序能换吗？"——不能。必须先测空烧杯质量。如果先测湿烧杯，烧杯内壁残留的水会使空烧杯重力偏大，导致G排偏小。
  3. "金属块没有完全浸没，实验还能验证阿基米德原理吗？"——可以。阿基米德原理对任意 V排 都成立。但必须准确记录此时 F示 和对应的 G排。
  4. "如果金属块接触了溢水杯底部，对结果有什么影响？"——底部给金属块支持力 → F示偏小 → F浮偏大 → F浮 > G排，无法验证原理。

⚠ 常见误区提醒

  • ❌ "浮力与深度有关" → ✅ 阿基米德原理中 F浮 = ρgV排，与深度无关。物体完全浸没后，再深也不会增大浮力。
  • ❌ "飞机升力是因为伯努利原理——气流上下表面路程长的说法有争议" → ✅ 确实！学术界对"等时到达"说存有争议。更准确地说，机翼使气流向下偏转（牛顿第三定律的反作用力）也是升力的重要贡献。两种解释都对，共同起作用。
  • ❌ "铁块沉水是因为铁太重了" → ✅ 铁沉水是因为铁的密度 > 水的密度。轮船也是铁做的但浮在水上——因为轮船是空心的，排开大量水，F浮 = ρ水 g V排 巨大。
  • ❌ "大气压强是因为空气有重量" → ✅ 对了一半。大气压强本质上是空气分子无规则热运动对物体表面的持续撞击（类似气体压强）。高度越高空气越稀薄，撞击越少，气压越低。
  • ❌ "高压锅是增大压强来煮熟食物" → ✅ 对——增大气压 → 提高水的沸点 → 温度更高 → 食物更快熟。

🧪 家庭小实验：马德堡半球简易版

  1. 准备两个一样的吸盘挂钩（超市有卖），对在一起用力压紧挤出空气。
  2. 尝试拉开——两个小吸盘产生的力就非常大，拉不开！
  3. 稍微掀开一角让空气进入——瞬间就分开了。这就是大气压强的力量。

🧪 家庭小实验：流体压强体验

  1. 拿两张纸，面对面靠近（间距约3-5cm）。
  2. 往两张纸之间吹气——纸不是被吹开，而是靠近了！
  3. 原理：吹气使纸间空气流速增大 → 压强减小 → 外侧大气压把纸压在一起。

🧪 家庭小实验：自制密度计

  1. 准备：一根吸管、一些橡皮泥（或黏土）、一杯清水、一杯浓盐水。
  2. 吸管底部用橡皮泥封口加重，让它能竖直漂浮。
  3. 分别放入清水和盐水中——在盐水中吸管露出更多！
  4. 原理：盐水密度更大，同样的浮力只需要排开更少的体积。
