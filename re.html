温度与温度计

我们怎么知道有多热？

摄氏温度 t（°C）：一个标准大气压下冰水混合物为 0°C，沸水为 100°C，之间均分 100 等份。

温度计原理：液体热胀冷缩。体温计测完不会自动回落（缩口设计），使用前要甩一甩。

🧪

物态变化 —— 六种变身

物质在固/液/气之间来回转换

吸热过程：熔化（固→液）、汽化（液→气）、升华（固→气，如干冰/樟脑丸）

放热过程：凝固（液→固）、液化（气→液）、凝华（气→固，如霜/雪）

晶体有固定熔点（如冰 0°C），非晶体没有（如玻璃、沥青——加热慢慢变软）。

💧

蒸发 vs 沸腾 —— 都是汽化，但不一样

一个偷偷摸摸，一个轰轰烈烈

对比蒸发沸腾
温度条件任何温度下都能发生达到沸点（100°C 标准大气压）
发生部位只发生在液体表面液体表面和内部同时发生
剧烈程度缓慢剧烈（大量气泡上升）
影响因素温度/表面积/空气流速气压（气压高沸点高）
🏯高原上煮饭煮不熟——气压低 → 沸点低（可能 80°C 水就沸腾了）→ 温度不够高，饭煮不熟。需要高压锅提高内部气压来提升沸点。
🔥

热传递的三种方式 —— 热是怎么"跑"的？

传导需要接触，对流需要流体，辐射什么都不需要

方式传热媒介发生条件核心机制典型例子
热传导物体直接接触有温度差+接触热量从高温端传到低温端勺子放入热汤，勺柄变烫；暖气片
热对流液体和气体流体温度不均匀热流体上升、冷流体下沉——循环烧水时水在锅中翻腾；空调冷风下沉
热辐射不需要介质任何有温度的物体以电磁波（红外线）形式传热太阳照到地球；篝火烤暖身体
☀太阳的热量是辐射传过来的——太阳和地球之间是真空！不是传导（真空不能传热），也不是对流（真空中没有流体）。这就是为什么宇航员在太空中可以同时面向太阳的一侧极热、背对太阳的一侧极冷。
🏯保温瓶（热水瓶）遏制了所有三种热传递方式——双层玻璃抽真空（阻断传导和对流）、内壁镀银反射热辐射（阻断辐射）。

🌑

热平衡方程 —— 「热水+冷水，最终温度是多少？」

没有热量损失时：放出的热量 = 吸收的热量

Q吸 = Q放
即：c₁m₁(t - t₁) = c₂m₂(t₂ - t)

在没有热量损失（绝热条件）下，高温物体放出的热量等于低温物体吸收的热量，两者最终达到相同的温度 t。

☕100g 80°C 的水 + 200g 20°C 的水混合——最终 t = (100×80 + 200×20) / (100+200) = 40°C。
🍴金属块投入水中测比热容——测出金属初温、水初温、最终平衡温度，用 Q吸=Q放 算出金属的比热容。
🌊

比热容 c —— 「为什么水是地球的空调？」

水的比热容最大——最"难热"也最"难凉"

Q = c m Δt
Q 热量 (J) c 比热容 J/(kg·°C) m 质量 (kg) Δt 温度变化 (°C)

水的比热容：c水 = 4.2 × 10³ J/(kg·°C)

含义：1kg 水温度升高（或降低）1°C，需要吸收（或放出）4200 J 的热量。

🌊沿海城市冬暖夏凉——海水比热容大，夏天吸热多升温慢（凉爽），冬天放热多降温慢（温暖）。内陆地区正好相反。
🚗

热机 —— 汽油机/柴油机四冲程

把燃料的热能变成机械能——汽车的心脏

热机是把内能转化为机械能的装置。一个完整的工作循环包含四个冲程：

冲程活塞运动进气门排气门能量转换
吸气冲程向下开关吸入汽油+空气混合气
压缩冲程向上关关机械能 → 内能（混合气温度升高）
做功冲程向下关关内能 → 机械能（点燃爆发）
排气冲程向上关开排出废气

记忆口诀："吸压做排"——四个冲程中，只有做功冲程是发动机对外做功的，另外三个冲程靠飞轮的惯性完成。

汽油机 vs 柴油机：汽油机用火花塞点火（点燃式），柴油机用压燃式（压缩空气到高温，喷入柴油自燃）。柴油机效率更高、扭矩更大，但更笨重。

水的沸腾曲线：达到沸点后温度不再升高！

加热过程中水温持续上升（升温段）。到达 100°C 后，继续加热水温不再升高（沸腾段保持恒温）——热量全部用于水从液态变为气态（汽化潜热）。

⚡

能量守恒定律 —— 「宇宙的会计法则」

能量不会凭空产生，也不会凭空消灭

能量守恒定律：能量既不会凭空产生，也不会凭空消失，它只会从一种形式转化为另一种形式，或者从一个物体转移到另一个物体，而在转化和转移的过程中，能量的总量保持不变。

这是自然界最普遍、最重要的基本定律之一——大到宇宙演化，小到原子核反应，无一例外。

🌊水力发电：水的重力势能 → 动能（冲下）→ 涡轮机械能 → 发电机电磁能 → 电能。每一步都有能量损失（变成热能），但总能量不变。
🌎

温室效应与热岛效应

地球发烧了——物理学怎么解释？

温室效应：太阳辐射（短波）穿过大气层照到地面，地面升温后向外发射红外线（长波辐射）。大气中的 CO₂、甲烷等温室气体吸收长波辐射，把热量"锁"在大气层中——就像温室的玻璃一样。温室效应本身是地球保持温暖的前提（没有它，地球表面平均温度将是 -18°C），但人类活动导致温室气体超标，温室效应过度增强——全球变暖。

热岛效应：城市中心温度明显高于郊区。原因：①混凝土和沥青吸热多（比热容小，升温快）；②空调和汽车排热；③高楼阻挡空气流通；④绿化少。城市热岛效应使夏季空调能耗增加 10-20%。

🌳多种树可以缓解热岛效应——树叶遮挡阳光（减少辐射）、蒸腾作用带走热量（蒸发吸热）。城市绿化不仅是"好看"，更是物理降温手段！
🌧

人工降雨原理 —— 「催云下雨的物理学」

不是"造雨"——而是"催雨"

云中的水滴太小太轻，不会下落。人工降雨就是向云中撒播凝结核（如碘化银、干冰），让微小水滴有核心可以凝聚变大——大到足够重时，就下雨了。

两种方式：

① 冷云催化：撒干冰（固态 CO₂，-78.5°C）或碘化银——干冰升华急剧降温，使过冷水滴凝华为冰晶，冰晶长大下落融化变成雨。

② 暖云催化：撒盐粉、尿素——作为吸湿性凝结核，让水滴聚集变大。

🎊2008 年北京奥运会开幕式——为确保天气晴朗，气象部门在周边地区提前实施人工消雨（在雨云到达北京前就让它提前下掉）。
✨ 趣味冷知识
人类能承受的最高温度是多少？
人体核心温度超过 42°C 时，蛋白质开始变性（就像煮鸡蛋一样）——危及生命。但 1755 年一位英国医生记录：一位女性在持续高烧中体温达到 46.5°C，竟然奇迹般存活！而桑拿房里 100°C 你能待几分钟——因为干燥空气导热慢，且汗液蒸发带走大量热。
✨ 趣味冷知识
水在 0°C 结冰——为什么深海里的鱼不会冻住？
深海水温虽然接近 0°C，但高压使水的凝固点降低（就像高压锅让沸点升高一样）。加上海水含盐（盐水冰点低于 0°C），还有鱼体内有抗冻蛋白阻止冰晶形成——自然界真奇妙！
✨ 趣味冷知识
摩擦能生热——两只手搓热了知道。但两只手搓一搓能烧开水吗？
理论上可以！焦耳在 1843 年用实验证明：让重物下落带动桨叶搅拌水，水温上升——确定了热功当量：1 cal = 4.18 J。他花了数小时搅拌才让水温升高一点点。你要搓手烧开水……大概需要连续搓几百年。
✨ 趣味冷知识
为什么冰的表面很滑？
传统解释是"压力使冰融化形成水膜"——但现代研究发现，冰表面本身就有一层纳米级厚度的"准液态水层"，即使零下几十度也存在。这层超薄水膜才是冰滑的真正原因——压力融化理论无法解释为什么零下 20°C 的冰仍然很滑。

⚠ 常见误区提醒

  • ❌ "0°C 的冰和 0°C 的水温度相同，所以手感一样冷" → ✅ 0°C 的冰更冷！因为冰熔化需要吸收大量熔化热，从你的手吸热——你把手伸进 0°C 的水里比摸着 0°C 的冰暖和一些。
  • ❌ "沸腾时水温继续升高" → ✅ 达到沸点后继续加热，水温不再升高——热量全部用于汽化（水变水蒸气）。
  • ❌ "晒太阳是热传导" → ✅ 太阳和地球之间是真空——热量通过热辐射传来，不需要介质。
  • ❌ "对流只发生在液体中" → ✅ 气体中也发生对流——空调冷风下沉、热气球上升都是空气对流。
  • ❌ "温室效应是坏事" → ✅ 温室效应本身让地球保持温暖宜居——是过度增强的温室效应（全球变暖）才是问题。

🧪 家庭小实验：自制温度计

  1. 准备：小玻璃瓶（口服液瓶）、吸管、橡皮泥、色素水。
  2. 瓶里装满红色色素水，插入吸管，用橡皮泥封住瓶口。
  3. 手握瓶子——吸管中的水柱缓缓上升！放手后水柱下降。
  4. 原理：手握加温 → 瓶内空气热胀 → 推动液柱上升——这就是温度计的基本原理。

🧪 家庭小实验：蒸发吸热体验

  1. 左手蘸水，右手保持干燥。
  2. 同时对着两只手吹气——左手明显更凉！
  3. 原理：水蒸发吸收手上的热量（汽化吸热）。
  4. 拓展：夏天往地面洒水降温也是这个原理。

🧪 家庭小实验：观察热对流

  1. 找一个透明玻璃杯，倒满水。滴入几滴酱油或色素。
  2. 用酒精灯或蜡烛加热杯子底部一侧（请大人操作）。
  3. 观察——可以看到有色水流上升、无色水流下沉的流动路径！
  4. 这就是热对流——热水上升、冷水下降的循环。
